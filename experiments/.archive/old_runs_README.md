# Experiment Runs

`pilot_dev/` and `main_dev/` contain development records only. They are useful
for checking the workflow but must not be copied into the final result table.

- `manual/` is a blank four-item review pack.
- `llm_only/` currently contains DORA-15 and DORA-18 only.
- `agentic_rag/` currently contains DORA-15 and DORA-18 only, using the existing
  DORA development corpus.

`main_working/manual/` contains the same blank forms for all 40 selected items.
The researcher may complete them later, but should avoid opening the matching AI
answer while reviewing an item. `main_dev/` contains all 20 DORA items for both
AI methods; the AI Act items have deliberately not been run.

After the AI Act corpus is ready, run all four pilot items. Pilot items and the
main dataset must be run again after the protocol and corpus are frozen before
their numbers can enter the main experiment.
