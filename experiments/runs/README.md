# Experiment Runs

`pilot_dev/` contains development records only. They are useful for checking the
workflow but must not be copied into the final result table.

- `manual/` is a blank four-item review pack. Fill it before reading the AI
  answers if the work will be used as the pilot baseline.
- `llm_only/` currently contains DORA-15 and DORA-18 only.
- `agentic_rag/` currently contains DORA-15 and DORA-18 only, using the existing
  DORA development corpus.

The two AI Act items have deliberately not been run. After the AI Act corpus is
ready, complete the Manual pack first and then run all four pilot items. Pilot
items must be run again after the protocol and corpus are frozen before their
numbers can enter the main experiment.
